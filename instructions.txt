Capstone Project 1 (HTML)
You will build a multi-page personal website (without CSS/styling) that demonstrates everything you have learned so far.

Project Requirements:
Structure & Pages
The website must have at least 4 pages:

Home (introduction about yourself)
Education (table showing your education history)
Weekly Schedule (a full weekly timetable using a <table>)
Contact Me (a form with various input types)

All pages must be interconnected using anchor (<a>) tags.
Include a favicon in your website.
Include a profile picture, optionally circular.

HTML Content Usage
Use headings, paragraphs, and lists (<ul>, <ol>) on the Home page.
Use links and anchor tags (both internal navigation and at least one external link).
Add at least two images (e.g., your profile picture, hobby image).
Use <meta> elements in the <head> section (e.g., charset, description, author).
Use UTF-8 encoding and display at least one emoji on your page.
Use title element properly for each page.

Tables & Layouts
Education page: Present education history in a tabular format.
Weekly Schedule page: Create a 7-day schedule table (merge Saturday & Sunday if you want).

Forms
Contact Me page must contain a form with:
Text inputs (name, email, etc.)

Optional:
Radio buttons
Checkboxes
Dropdown/select list
Textarea

Submit button
Form must be submitted as plain text (enctype="text/plain"), optionally to your email.

Extra Tasks
Add a questionnaire page with multiple input types (yes/no questions, checkboxes, ratings, etc.), and make it send results to your email.
Add some HTML5 semantic element (<header>, <nav>, <section>, <article>, <footer>).

Git & Publishing
Create a GitHub account.
Create a repository and push your website into GitHub.
Publish your website using GitHub Pages.
Share the live link with your instructor/classmates.
