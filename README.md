# Personal Website — Capstone Project - Homework

## Overview
This project is a personal website created as part of my Web and Mobile I course homework.  
So far, it demonstrates how HTML and CSS work together to build a structured, visually consistent, and responsive design.

The website includes:
- A **fixed navigation bar** that remains visible while scrolling and changing pages.  
- Pages such as **Home**, **Education**, **Weekly Schedule**, **Gallery**, and **Contact Me**.  
- Consistent background color, font style, and spacing across all pages (I tried to have a color palette).  
- A **responsive photo gallery** (3 images per row on desktop, 1 on mobile)(it works just fine on google chrome but there are some issues that i couldn't solve, that appear in safari).  
- A **contact form** styled with custom colors and rounded inputs.

## What I Learned

- Difference between **inline, internal, and external** CSS and why external stylesheets are preferred.  
- Creating reusable styles with **class**, **id**, and **pseudo-classes** like `:hover`.  
- Styling images with **border-radius** (for a circular profile picture which was a struggle when i forgot the profile picture and was trying to understand why my gallery was filled with circular photos) and hover animations for smooth growth.  
- Designing an elegant **Education table**(the fact that I have a high number of schools in the education table is the not so fun part), styled lists, and a well-structured **Contact Me** form.  
- Using the **box model**—margin, border, and padding—to control spacing and layout.  
- Practicing **display**, **position**, and **float** properties to arrange elements.  
- Using **media queries** to adapt layouts for smaller screens.

These techniques helped me understand not only *how* to style elements, but also *why* certain approaches (like flexbox or grid) are more efficient than older methods such as floats or manual positioning.
